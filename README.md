# DLP Priority

Statische iPhone-optimierte Web-App für Disneyland-Paris-Priority-Karten.

## Enthalten
- Mehrere Karten mit Umbenennen und Löschen
- Mehrere Erinnerungen pro Rückkehrzeit
- Ton und Vibration separat in den Haupteinstellungen
- Notizen pro Rückkehrzeit
- Export und Import
- Parktag und Tageswechsel
- PWA-Manifest, Service Worker und Home-Screen-Icons

## GitHub und Vercel
Den Inhalt dieses Ordners in ein GitHub-Repository hochladen und das Repository anschließend bei Vercel importieren. Es sind keine Build-Einstellungen erforderlich.

Hinweis: Browser-Benachrichtigungen funktionieren abhängig von iOS-Berechtigungen und dem geöffneten bzw. installierten PWA-Kontext. Zuverlässige Hintergrund-Pushs bei vollständig geschlossener App benötigen zusätzlich einen Push-Dienst und ein Backend.
